# משמרת לילה

משחק יריות תלת־ממדי על מסילה (light-gun shooter) לדפדפן, בעברית, בהשראת משחקי ארקייד משנות ה־90.
שלושה שלבים בישראל — רחוב ראשי בצהריים, נמל חיפה בשקיעה ותחנת רכבת בלילה — עם בחירת מסלול בכל שלב, בוסים, נשקים מיוחדים, בני ערובה ואזרחים שאסור לפגוע בהם.

המשחק החי: https://israelb014.github.io/mishmeret-layla/

## דרישות

- Node.js 18 ומעלה (נבדק עם Node 26).
- דפדפן שולחני עם WebGL2: Chrome, Edge או Firefox, ועכבר.

## הרצה מקומית

```bash
npm ci
npm run dev
```

ואז לפתוח את הכתובת שמופיעה בטרמינל (בדרך כלל http://localhost:5173/mishmeret-layla/).

### מצב פיתוח (רק ב־`npm run dev`)

- `?stage=2&zone=4` — קפיצה ישירה לשלב ולאזור (מספור מ־1).
- `F1` — הצגה/הסתרה של מונה FPS.
- `?branch=right` — בחירת ענף המסלול כשקופצים לאזור שאחרי הפיצול.
- `?auto` — בוט שמכוון ויורה אוטומטית (לבדיקות), `?god` — בלי נזק.

כל אלה מוסרים אוטומטית מגרסת ה־production.

## בנייה

```bash
npm run build
```

התוצר נמצא בתיקייה `dist/` — אתר סטטי לגמרי, בלי שרת ובלי בקשות חיצוניות. לבדיקת התוצר:

```bash
npm run preview
```

## פריסה ל־GitHub Pages

הפריסה אוטומטית: כל `git push` לענף `main` מפעיל את ה־workflow שבקובץ `.github/workflows/deploy.yml`, שמריץ `npm ci && npm run build` ומפרסם את `dist/` ל־GitHub Pages.

בפעם הראשונה צריך להפעיל את Pages במאגר: Settings ← Pages ← Source: **GitHub Actions**.

## נכסים (Assets)

כל הדמויות, האנימציות, הרכבים, האביזרים, המשטחים, השמיים, הצלילים והמוזיקה הם CC0. הרשימה המלאה: [CREDITS.md](CREDITS.md) (וגם במסך הקרדיטים במשחק).

הנכסים המוכנים נמצאים ב־`public/assets/`. צינור העיבוד (המרה, דחיסת meshopt, טקסטורות WebP, אודיו OGG) נמצא ב־`tools/`:

```bash
npm run assets   # דורש את קבצי המקור שהורדו (ראו tools/assets-manifest.mjs)
npm run credits  # יוצר מחדש את CREDITS.md
```

## מבנה הקוד

- `src/core/` — רינדור, טעינה, אודיו, קלט והגדרות.
- `src/world/` — בוני הסטים, זונות, חומרים, שלטים ואפקטים.
- `src/actors/` — דמויות, אויבים, אזרחים ובוסים.
- `src/gameplay/` — מהלך המשחק, מסילת המצלמה, נשקים, ניקוד ואובייקטים.
- `src/ui/` — מסכים, HUD, אייקוני SVG ועיצוב.
- `src/data/` — תוכן השלבים כנתונים (מסלולי מצלמה, אויבים, תזמונים).
